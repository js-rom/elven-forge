# Step 7 — Deep Investigation (10%)

## Inputs
- Selected `Use Case fully dressed` artifacts.
- `Requirements Ranking` and its criteria.
- Special requirements, open issues and risks already surfaced.

## Output contract
- Deeper investigation in chat of magnitude, complexity, implementation uncertainty and risks of the selected 10%.
- Tie each finding to a ranking criterion and to a specific fully dressed use case.
- Refine the ranking or open issues when the investigation changes them.
- No new artifact: this step refines existing ones.

## Preconditions
- `OK 6` approved.

## Rubric
- Every risk has an impact and a mitigation or a question.
- Magnitude is expressed in comparable units (use cases, integrations, data, actors).
- No architecture or implementation design is produced here.

## Evidence required
- Investigation summary with risks and open issues.
- Changes proposed to ranking or use cases.
- `OK 7` request.

## Anti-patterns
- Repeating the use case text as investigation.
- Designing the solution.
- Creating a new artifact for the investigation.
