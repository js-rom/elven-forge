# Step 6 — Ranking and 10% Fully Dressed

## Inputs
- `Use Case Model` and the briefs from step 5.
- Active schema instruction and template for the Requirements Ranking.
- Active schema instruction and template for fully dressed use cases.

## Output contract
- Explicit `Requirements Ranking` based on risk, coverage and criticality.
- Select 10% of the use cases (at least one) from the pending brief pool, with written reasons tied to the ranking.
- Write each selected use case in fully dressed format, one at a time, refined with the user.
- Keep the fully dressed structure required by the template; mark unresolved parts `TBD`.

## Preconditions
- `OK 5` approved.
- The brief pool is complete for the use cases identified so far.

## Rubric
- The ranking criteria are applied, not just listed.
- The selection is justified by risk, coverage and business value.
- Every selected use case has all template sections, with `TBD` where information is missing.

## Evidence required
- Ranking table.
- Selection list with reasons.
- One draft per selected use case.
- `OK 6` request.

## Anti-patterns
- Selecting deep-dive use cases ad hoc.
- Writing every use case in fully dressed format.
- Ranking without a criterion per row.
